# ⚡ TaskFlow - Modern Web & JS Projesi

HTML5, CSS3 ve saf JavaScript (Vanilla JS) kullanılarak geliştirilmiş modern bir görev yönetimi paneli.

## 🚀 Özellikler
- **Görev Yönetimi:** Görev ekleme, tamamlama ve silme.
- **Dinamik Filtreleme:** Tümü, Bekleyen ve Tamamlanan sekmeleri.
- **Kalıcı Veri:** LocalStorage ile veriler tarayıcıda saklanır.
- **Öncelik Etiketleri:** Düşük, Orta ve Yüksek öncelik seviyeleri.
